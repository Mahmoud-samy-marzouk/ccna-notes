# CCNA Notes

My study notes and Cisco Packet Tracer labs while preparing for the CCNA certification.

## Structure

| Folder | Topic |
| --- | --- |
| `01-networking-basics` | Networking fundamentals: OSI and TCP/IP models, devices, topologies |
| `02-ip-addressing-subnetting` | IPv4/IPv6 addressing and subnetting practice |
| `03-switching` | VLANs, trunking, STP, EtherChannel |
| `04-routing` | Static routes, OSPF, first-hop redundancy |
| `05-security` | ACLs, port security, VPN and wireless security basics |
| `06-automation` | Network automation basics and an introduction to Python |
| `07-packet-tracer-labs` | Cisco Packet Tracer lab files (.pkt) with a short note per lab |

## 14-day plan

See [14-day-ccna-plan.md](14-day-ccna-plan.md) for a two-week study plan.
