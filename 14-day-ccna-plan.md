# 14-Day CCNA Study Plan

A two-week push through the main CCNA topics. Adjust the pace as needed.

- **Day 1:** Networking basics - OSI and TCP/IP models
- **Day 2:** Network devices and topologies
- **Day 3:** IPv4 addressing
- **Day 4:** Subnetting practice (VLSM)
- **Day 5:** IPv6 addressing basics
- **Day 6:** Switching - VLANs and trunking
- **Day 7:** Switching - STP and EtherChannel + review lab
- **Day 8:** Routing - static routes
- **Day 9:** Routing - OSPF single area
- **Day 10:** Security - ACLs
- **Day 11:** Security - port security, wireless and VPN basics
- **Day 12:** Automation basics - APIs, JSON, intro to Python
- **Day 13:** Mixed Packet Tracer practice labs
- **Day 14:** Full review and a practice exam

Each day: read the topic, write short notes in the matching folder, and build one small Packet Tracer lab when possible.
